# AI 工具使用揭露（草稿，送件前請依實際情況確認）

依競賽規定，以下區分「開發過程使用的 AI」與「作品本身提供的 AI 功能」。

## 一、開發過程使用的 AI

| 工具 | 用途 | 參賽者的角色 |
|---|---|---|
| Claude（Anthropic，Claude Code 工作環境） | 程式架構規劃、3D 場景與互動模組撰寫、除錯、自動化瀏覽器測試、公開資料檢索與整理 | 提出企劃與需求、決定五大區域與任務設計、審閱與修改內容、核對史實、實際操作測試 |
| ChatGPT（OpenAI） | 企劃內容發想、互動設計構想、資料整理（企劃階段） | 統整為正式企劃案 |
| （其他實際使用的工具請補列） | | |

說明：
- 所有星雲大師生平與思想內容，皆經參賽者依公開資料核對，並在作品中逐段標示出處（見 `src/data/sources.js`）。
- 3D 場景、建築、人物與願行卡皆由程式即時繪製，未使用 AI 生成圖片、未使用大師肖像與聲音。

## 二、作品本身提供的 AI 功能

| 功能 | 位置 | 運作方式 |
|---|---|---|
| AI 智慧導覽／講堂問答 | 第四區 AI 智慧講堂、全島右下角 AI 導覽 | RAG：先以中文 BM25 從 36 段知識庫檢索相關段落，再交由大型語言模型依據段落回答，回答附出處編號與原始連結 |
| 三種導覽模式 | 同上 | 知識導覽（史實）／思想理解（白話解釋＋例子）／生活實踐（依三好四給給建議） |
| 情境選擇分析 | 第三區七座亭子 | 使用者做出選擇後，AI 依情境、選項與知識庫，說明這個選擇對他人可能帶來的影響 |
| 練習句回饋 | 第三區七座亭子 | 使用者寫下自己會說的話或做法，AI 指出優點並提供修改示範 |
| 個人化學習回饋與挑戰建議 | 第五區願行台 | AI 依使用者在任務中的選擇，給出簡短回饋與一項生活挑戰（不做心理或人格判斷） |

- 模型與服務：正式部署使用 Anthropic Claude API（模型：＿＿＿＿，依 Vercel 環境變數 `AI_MODEL` 實際設定填寫）。
- 安全設計：金鑰僅存於伺服器環境變數；每 IP 每分鐘限 12 次、全站每日上限；輸入長度驗證；匿名互動紀錄。
- 內容防護：系統規則要求 AI 不冒充星雲大師、不捏造語錄、資料不足時明確表示無法確認、不提供未經證實的教義詮釋、遇到危機語句時提供安心專線 1925 與生命線 1995。
- 誠實降級：AI 服務無法連線時，畫面明確標示「AI 暫時無法連線」，只顯示知識庫原文，不以固定文字假裝為 AI 回答。
