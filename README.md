# 三好四給島：AI 沉浸式互動探索與實踐平台

Three Acts of Goodness & Four Givings Island – An AI Immersive Interactive Platform for Exploration and Practice
2026 三好 AI 創新應用競賽｜大專組 B 類（AI 數位應用實作類）參賽作品

走進大師的智慧，讓佛法在生活中實踐。一座可以在瀏覽器中直接走進去的 3D 島嶼：
**探索 → 學習 → AI 對話 → 三好四給任務 → 願行實踐**。

## 島上的區域

| 區域 | 互動 |
|---|---|
| 山門・源頭碑 | 導覽員小蓮介紹三好四給（身口意三業、慈悲喜捨四無量心）；四題快問快答，答對才能出發；選玩的四給配對遊戲 |
| 三好村 | 阿婆（做好事）、阿哲（說好話）、小雨（存好心） |
| 四給街 | 小安（給人信心）、李伯伯（給人希望）、阿姨（給人歡喜）、敏娜（給人方便） |
| AI 智慧講堂 | RAG 問答，三種模式：知識導覽、思想理解、生活實踐；每則回答附可追溯出處 |
| 善念影音堂 | 連到佛光山與人間衛視公開影片的延伸觀看 |
| 願行台（山頂） | 旅程回顧、AI 學習回饋與挑戰建議、產生可下載的願行卡（1080×1350 PNG）；四關全部完成後回到山頂，天色轉為黃昏、鏡頭拉到遠景，整座島上空放煙火（粒子系統，聲音以 Web Audio 即時合成），並出現祝福字幕 |

### 七位島民：每一站五個步驟

1. **觀看・聆聽**：島上發生的事與島民的心聲。
2. **島上任務（操作）**：撿柳丁、和三位組員對話（選出化解火氣的愛語）、在湖邊蒲團靜心呼吸後以戒定慧熄滅貪瞋痴三把心火、找出小安做得好的三件事、點亮老街的燈、撿回感謝卡、帶迷路的同學到講堂。
3. **回到生活**：情境選擇，AI 依知識庫分析這個選擇對他人的影響。
4. **佛法小課**：這份善行背後的佛法（《十善業道經》身三口四意三善業、四攝法、戒定慧與貪瞋痴、四無量心、廣結善緣），附出處。
5. **佛法挑戰**：分類、選擇與愛語改寫，每一題都要答對才算完成（答錯會說明原因，可以再選）。

### 福德與智慧（福慧雙修）

每做到一件事（任務中的每一件事、對話、快問快答與佛法挑戰的每一題、情境選擇、寫下自己的話、向 AI 提問、願行台的 AI 學習回饋、完成一站、過一關、撿起善念光球、感化心魔），人物頭上都會冒出這次增加的「福德」與「智慧」，左側善念地圖顯示累積總數。動手幫忙偏重福德，學懂佛法偏重智慧，一次就答對得到的更多；每件事只算一次。各項數值集中在 `src/data/merit.js`，方便調整。

### 四大心魔（完成第一站之後開始）

| 心魔 | 代表的習氣 | 行為（AI） | 遊戲效果 | 化解方法 |
|---|---|---|---|---|
| 自私鬼 | 自私、不願分享 | 發現玩家就主動追 | 被追上福德減 5 | 撿善念光球後追上碰它（布施、關懷） |
| 懈怠鬼 | 懈怠、拖延 | 慢慢跟隨 | 靠近時腳步變沉重；被抓住智慧減 3、懶洋洋 3 秒 | 撿善念光球後追上碰它（精進、行動） |
| 貪心鬼 | 貪欲、佔有 | 搶吃島上的善念光球；玩家最近撿越多光、身上發著光，越遠就盯上 | 追上時搶走身上的光（福德減 2）或福德減 4 | 它伸手要光時，主動把光布施給它（知足、布施）；完成阿婆、阿姨兩站後它比較不貪 |
| 嫉妒鬼 | 比較、嫉妒 | 平常隱身，冷不防瞬移到玩家前方、繞著玩家 8 秒 | 畫面干擾、遮蔽部分視野、腳步變慢 | 走近它選一句隨喜的話（隨喜、讚歎）；完成小安那一站後干擾減半；善念之光能趕走它 |

- **善念光球**：步道上 11 顆發光的小蓮花（固定位置，撿走或被貪心鬼吃掉後 45 秒重生），撿起來善念之光守護 15 秒。
- 感化後變成歡喜精靈、精進精靈、知足精靈、隨喜精靈，並以《佛說八大人覺經》第三、第四、第六覺知與〈普賢行願品〉「隨喜功德」說明這份轉化。
- **隱藏成就「光明之境」**：四大心魔還在時島上蒙著一層淡淡的灰；四隻都感化後，陽光轉為溫暖的金色、空中飄滿光點，善念地圖多一枚「光」徽章。
- 站點前、對話對象與蒲團旁、碼頭是安全區；開著面板、對話、帶路任務進行中時，心魔不會追人。
- 畫面提示：心魔頭上的名牌（遊蕩中／追你中／伸手要光／干擾你！／已感化）、畫面下方的狀態提示、畫面四周的氣息，音效以 Web Audio 即時合成。

### 島民在做的事

島民不再直挺挺站著，各自在自己的地方做事：小蓮在源頭碑前掃地（有人走近就停下來揮手）、阿婆彎腰撿柳丁（幫完後坐在小凳子上剝柳丁）、阿哲坐在板凳上盯著手機、小雨在湖邊的樹下抱膝而坐（靜下來之後盤腿靜坐）、小安坐在亭子裡畫畫、李伯伯在亭子裡修一盞燈籠（老街的燈亮起後燈籠也亮了）、阿姨在亭子裡的小推車炒菜、敏娜拿著地圖東張西望；三位組員各自抱胸、托腮、低頭踢石子生悶氣。海邊還有人坐在礁石上釣魚，三好村旁有人在劈柴。

## 技術架構

- 前端：原生 ES Modules ＋ Three.js r160（已內附於 `vendor/`，不依賴外部 CDN），無建置步驟。
- 3D：程序化生成的地形、溪流與木橋、拱橋、殿宇、亭子、牌坊、七層塔與蓮池；人物與任務物件為原創程式繪製。
- 操作：鍵盤（WASD／方向鍵）或手機搖桿自由行走（輕快小跑步，步伐依實際移動距離換腳、起步停下有加減速）；走路時鏡頭平順地轉到人物背後、約 45 度俯視，轉身往回走時不翻轉；被樹擋住時顯示人物輪廓；朝著橋走時會自動對準橋面。
- 引導：畫面上方「目前目標」、地上沿步道的金色箭頭與光柱、人物頭上的名牌。
- AI：
  - `src/ai/retrieve.js`：中文 BM25（單字＋雙字）檢索，前後端共用。
  - `src/ai/prompts.js`：系統規則（不冒充大師、不捏造語錄、資料不足時明說、附出處編號、不做心理診斷）＋檢索段落。
  - `api/ai.js`：Vercel Serverless Function，金鑰只放伺服器環境變數；含輸入驗證、每 IP 每分鐘 12 次與全站每日上限、匿名互動紀錄。
  - `src/ai/client.js`：正式站呼叫 `/api/ai`；在 claude.ai 預覽時改用平台內建 Claude；兩者都無法使用時明確標示「AI 暫時無法連線」，只顯示知識庫原文，**不會把固定文字偽裝成 AI 回答**。
- 知識庫：`src/data/kb.js`（42 段，生平／人間佛教／三好四給／佛法基礎），每段標註來源；來源清單在 `src/data/sources.js`。
- 進度：`localStorage`，不需登入；任務進行到一半重新整理也會保留。
- 背景音樂：瀏覽器規定使用者互動前不能自動播放聲音，載入完成時若被擋下，會顯示「點一下，進入三好四給島」，第一次點擊就開始播放。

## 部署（Vercel）

1. 把本資料夾推到 GitHub 新的儲存庫。
2. 在 Vercel 匯入該儲存庫（Framework Preset 選 **Other**，不需要 Build Command）。
3. 到 **Settings → Environment Variables** 新增：
   - `ANTHROPIC_API_KEY`：Claude API 金鑰（必填其一）
   - `AI_MODEL`：選填，預設 `claude-haiku-5-5`
   - 或改用 `OPENAI_API_KEY`（＋選填 `OPENAI_MODEL`，預設 `gpt-4o-mini`）
   - `AI_DAILY_CAP`：選填，全站每日請求上限，預設 4000
4. 重新部署。打開 `https://你的網址/api/ai` 應看到 `{"ok":true,"ai":true}`。
5. 實際在講堂問一題，確認回答下方顯示「AI 即時生成・依據島上知識庫」。

本機預覽：`python3 -m http.server 8000` 後開 `http://localhost:8000`（沒有後端時 AI 會顯示離線狀態）。
本機連同 AI 一起測：`npx vercel dev`（需先設定環境變數）。
